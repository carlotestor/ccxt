### 🔴 `trades.slice ()` does not transpile

`ts/src/test/Exchange/test.fetchTrades.ts:73` now reads:

```ts
const sortedTrades = exchange.sortBy (trades.slice (), 'timestamp');
```

`build/transpile.ts` only rewrites `.slice ()` when it has **arguments** — the Python rules at lines 523–524 are `\.slice \(([^\,\)]+)\,…\)` and `\.slice \(([^\)\:]+)\)`, and the PHP rules at 757–758 likewise require a first argument. A zero-arg `.slice ()` matches neither, so the call passes through verbatim into every generated target.
